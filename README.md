# 세카이 재화 기록

프로젝트 세카이 재화 수급·소비를 날짜별로 적고 월별·경로별로 합산해 보는 기록장.

- 사이트: https://dinored960018.github.io/sekai-tracker/
- 구성: `index.html` 한 파일. 빌드 없음.
- 저장: 기록은 브라우저 localStorage(`sekai-tracker-v2`)에만 남는다. 서버로 보내는 데이터는 없다.
- 로그인: 첫 화면에서 아이디와 비밀번호를 묻는다. 소스에는 원문 없이 PBKDF2 해시만 있다. 정적 페이지라 화면을 가리는 잠금이고 서버 인증은 아니다.
- 기기 이동: 관리 탭에서 JSON 백업을 받은 뒤 새 기기에서 백업 불러오기.

## 화면

- 입력: 구분은 네 가지. 보유량(지금 가진 수량을 적으면 지난 기록과의 차이를 수급·소비로 자동 기록, 크리스탈 제외), 수급·소비(얻거나 쓴 양을 직접 적기), 기존(기록 시작 전에 갖고 있던 수량). 한 번도 기존을 정하지 않은 재화는 첫 보유량 입력을 기존으로 저장한다.
- 요약: 재화별 일별 흐름 그래프, 경로별 합산, 기간 합산, 현재 보유(기존 + 수급 − 소비)
- 추이: 재화 그룹별 월별 추이와 일별 기록
- 기록: 날짜별 상세 기록과 삭제
- 관리: 재화 이름·색 변경, 추가, 삭제, 백업·CSV 내보내기

## 아이콘

상단과 로그인 화면의 시노노메 아키토 아이콘(`img/akito-icon.webp`)은 프로젝트 세카이 공식 사이트(pjsekai.sega.jp) 캐릭터 페이지의 아이콘을 정사각형으로 잘라 줄인 것이다. 비공식 팬 사이트이며 그림의 권리는 원저작권자에게 있다.
